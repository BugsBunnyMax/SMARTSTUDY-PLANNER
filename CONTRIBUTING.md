# Contributing to SmartStudy Planner

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a feature branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Commit with clear messages: `git commit -m "feat: add new feature"`
6. Push to your branch: `git push origin feature/your-feature-name`
7. Create a Pull Request

## Code Standards

### Commit Messages
- Use conventional commits: `feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `test:`, `chore:`
- Keep messages concise and descriptive
- Example: `feat: add task priority filtering`

### Code Style
- Use ES6+ syntax
- Follow existing code patterns
- Add comments for complex logic
- Use meaningful variable names

### Testing
- Write tests for new features
- Ensure existing tests pass
- Maintain >80% code coverage

## Pull Request Guidelines

- Link related issues
- Describe your changes clearly
- Include before/after screenshots for UI changes
- Ensure CI/CD checks pass
- Request review from team members

## Development Workflow

```bash
# Create feature branch
git checkout -b feature/task-filtering

# Make changes and commit
git add .
git commit -m "feat: implement task filtering by priority"

# Push and create PR
git push origin feature/task-filtering
```
